# Viktor Kvist · Portfolio & Showcase

Personlig webbplats och portfolio utvecklad inom ramen för utbildningen på IHM Business School (AI Tech & Digital Marketing).

## 🚀 Innehåll & Funktioner
- **Semantisk HTML5 & Responsiv CSS**: Byggd från grunden utan tunga ramverk för snabb laddningstid och tillgänglighet.
- **Interaktivitet**: Skräddarsydd JavaScript för dynamiska element, navigation och animeringar.
- **Tillgänglighetsanpassad**: Snabbhopp (`skip-link`), strukturerade rubriker och färgkontraster.

## 📂 Filstruktur
- `index.html` – Huvudsida och layout
- `css/style.css` – All styling, variabler, responsiva breakpoints
- `script.js` – Logik och interaktioner
- `img/` – Bilder och grafiska resurser

## 🛠️ Lokal utveckling
Öppna bara `index.html` i valfri modern webbläsare, eller kör via Live Server.
